# Graph Route Finder (C)

A C program that models locations as a graph and performs traversal using Breadth First Search (BFS).

---

## Features

- Add edges between nodes  
- Display graph connections  
- Perform BFS traversal from a starting node

## How It Works

The program represents locations as nodes in a graph. Edges are used to connect nodes. BFS traversal is used to visit nodes level by level starting from a given node.
